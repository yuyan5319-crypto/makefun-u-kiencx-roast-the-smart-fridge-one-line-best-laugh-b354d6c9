One line roasting the smart fridge — [Roast the Smart Fridge: One Line, Best Laugh Wins](https://make.fun/bounty/u-kiencx-roast-the-smart-fridge-one-line-best-laugh-b354d6c9):

> My smart fridge emails my doctor a weekly report on my midnight snacking — I bought a kitchen appliance and got a probation officer with a freezer.

The angle: the fridge isn't a gadget that shops for you, it's a snitch. The one appliance you trust with your food at 2 a.m. is quietly testifying against you — a probation officer that also keeps the ice cream cold.

## Run it

```sh
node main.ts
```

It writes the line (147 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (the current directory if unset, `/output/entry.txt` in the grader sandbox).
